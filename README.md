# 📚 Web Scraping Flask Application

## 🚀 Overview  
This project is a web application built with Flask that scrapes data from multiple library websites and displays the aggregated information in a user-friendly interface. The app fetches live data on-demand without storing it in a database.

## ✨ Features  
-  Scrapes data from multiple online library sources  
-  Displays real-time results on a web page  
-  Search functionality to filter the scraped data  
-  Built using Python, Flask, and BeautifulSoup

## ▶️ Usage  
1. Run the Flask application:  
   python both.py  # or your main Flask app filename

2. Open your web browser and go to:  
   http://127.0.0.1:5000

3. Use the search bar to query the scraped library data.

## 🛠️ Technologies  
- Python  
- Flask  
- Requests  
- BeautifulSoup  
- HTML/CSS
